# 实现说明与验收

对应《三维几何可视化工具改进分析》，更新于 2026-10-04。

本次以正方体为对象，完成可靠编辑、等价具体展开变换，并交付标准观察、折叠演示和教学复用的基础版本。原路线中的规模优化、长方体与组合体展开仍属于后续阶段。

## 1. 直接体验核心需求

1. 选中正方体，点击 **展开选中**，选一种展开类型并绘制非对称图案。
2. 点击 **整体左转／右转／上翻／下翻**，或浏览 **24 个具体展开**。图案随整体参考姿态改变位置与平面方向；折回后仍是同一个带图案的正方体。
3. 切换其他展开类型，参考面与参考方向继续保留。**返回上一个展开**按本次会话中的访问顺序返回。
4. 点击 **回到绘制布局**，恢复最近一次实际绘制时的类型、具体状态和整图查看方向。
5. 点击 **应用到立方体**，然后重新展开。有绘制记录时默认打开绘制布局；**上次应用布局**可找回上次提交时正在查看的状态。没有绘制记录时打开上次应用布局。
6. 使用 **保存布局书签**保留最多 12 个布局。项目保存和自动保存均包含这些记录。

**整图旋转 90°**控制画布查看方向；**整体变换**改变同类展开的具体面分配及对应方向。这两个操作分别保存，不会混为一谈。

## 3. 展开几何与编辑数据

`src/model/netVariants.ts` 是具体展开的计算入口。每个状态保存：

```ts
type NetState = {
  templateId: string;
  referenceFace: FaceId;
  referenceTurn: number; // 0、1、2、3
  viewTurn: number;      // 整图查看方向，独立于具体展开
};
```

每种类型采用一个确定的参考格：邻接数最多，平局时按行、列排序。参考格上的面及其有向坐标系唯一确定六面分配和全部纹理方向。整体转动同时更新法线和两个面内轴，面归属与图案旋转由同一套几何推导得到。

跨类型目前沿用相同的参考面和面内方向。它保持固定立体的全部图案关系，但不同类型的切缝不同，不保证所有平面相邻格都仍相邻。保留公共面块的自动匹配属于进一步增强。

`src/draw/EditSession.ts` 持有六面源图案草稿与局部历史。平面展开的画布只是这些源图案的视图；只有实际绘制后才回写草稿。查看、变换和切换模板不会反复旋转保存源像素。切边、折线、面名和选中框在覆盖层绘制，不进入作品图案。

`src/model/folding.ts` 按共享边产生刚体变换。闭合终点统一回到原带标记正方体的坐标系，因此浏览不同具体展开时，闭合后的图案关系一致。动画遵循铰链约束，当前没有纸张厚度、自碰撞检测或自动避碰路径。

## 4. 保存、迁移与内存

项目格式更新为 **version 3**，支持读取旧版 1、2。保存内容包括组件组、单体及姿态、透明图案、面底色、当前展开、绘制布局、书签、相机和各组旋转中心。选区、折叠播放进度、临时预览以及本次会话的返回路径不随项目保存。

旧文件的面图案与材质颜色原本相乘。迁移时把旧着色效果按线性 RGB 合成到原图案中，保留原外观；不会尝试把旧图片中的背景猜测性地抠除。因此旧版不透明底图覆盖的区域，仍应先擦除后才能露出新的面底色。

自动保存保存已提交的场景编辑，约在最后一次操作后 900 ms 写入 IndexedDB。未应用的草稿不写入自动保存。重新进入页面会提示存在本机作品，用户通过 **恢复自动保存**查看时间与单体数量后恢复。手动下载项目会保存下载时的相机状态；自动保存中的相机状态对应最近一次场景提交。练习记录独立存入本机 localStorage，最多保留 100 次。

文件读取上限：32 MB、1000 个单体、100 个组件组、每面数据 URL 4 MB。这是格式限制，不代表已验证所有设备都适合同时编辑 1000 个带纹理单体。

局部编辑历史最多 100 条、独立像素缓冲预算 48 MiB；场景历史最多 100 条，按快照和主要资源估算 64 MiB，保留至少一条命令。历史中的共享对象有引用计数，避免裁剪旧命令时释放仍被其他命令引用的纹理。预算不是浏览器或 GPU 总内存上限。

## 5. 观察与学习约定

世界 Y 轴向上，Z 正方向为前方：正视 `(x,y)`，俯视 `(x,-z)`，右视 `(-z,y)`。投影在组件组变换后计算网格并集；一个格保留该视线上全部单体。深度层数按不同世界位置统计，跨组同位置叠放不会虚增深度。图案模式使用最靠近观察者的面；半透明组在投影中仍作为存在的实体处理，不模拟透视混色。

**正交三视图**同时显示一个可旋转立体和三个固定方向投影。旋转观察相机不改变标准投影；悬停立体可看到它在三个方向的对应格；点击投影格可查看并选择由近及远的来源单体。

练习第一版为三道可重复的精选题：6 单体组合的正视轮廓、展开图中 A 的对面、上表面箭头闭合后的方向。题目使用固定几何关系评分，提供投影差异或折叠验证。尚无随机题库、题目编辑器或多解立体还原评分。

展开图导出可分别控制图案、面名、切边和折线；三视图导出保留统一比例与方向说明。纸模型毫米尺寸、粘贴边及 PDF 排版未包含在本次版本。

## 6. 验证方式

```sh
npm install
npm run dev
npm run build
npm test
npm run test:e2e
```

浏览器测试使用 Playwright，配置会优先使用本机 Chrome，其次 Edge。其他环境可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`指定浏览器路径。测试自动启动本地 Vite 服务。

几何与数据测试共 11 项：

- 独立从 Three.js BoxGeometry 的真实 UV 和顶点推导纹理坐标系，检查全部 264 个具体展开。
- 检查 24 状态的可达性、逆变换、四次 90° 恢复，以及全部跨类型有向参考往返。
- 检查 264 个状态在多处进度下的共享边连续、刚体变换及闭合终点。
- 检查旋转组内的主轴旋转、非原点枢轴、坐标往返、投影遮挡和图片方向。
- 检查文件错误与历史资源引用；预计算模板与保留的生成器结果一致。

浏览器回归共 12 项，全部通过，覆盖草稿取消、局部撤销、绘制后切换及重新读取恢复、坏文件和坏图片原子失败、指针取消、焦点管理、透明非对称像素的 264 状态往返、底色与笔画分离、三视图导出、自动保存恢复、三类练习、透明度事务以及 390px 窄屏流程。截图位于运行测试后的 `test-results/`，不纳入版本控制。

已通过 TypeScript 与生产构建。Three.js 所在的主包仍超过 Vite 默认 500 kB 提示阈值；编辑器、三视图和练习已按需加载，没有通过提高阈值隐藏提示。模板已预计算，启动时无需枚举展开树。
