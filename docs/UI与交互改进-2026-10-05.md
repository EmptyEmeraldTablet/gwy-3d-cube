# UI 与交互改进

本轮针对实际使用中反馈的四个问题：新增和堆叠容易混淆、展开画板偏小、单面编辑与展开编辑的关系不清楚、按钮缺少层次。

## 1. 分析与对应调整

| 问题 | 原因 | 本次调整 |
| --- | --- | --- |
| “添加立方体”和“贴面堆叠”像是同一种操作 | 两者在初始选中右面时，可能恰好都放到右侧；原按钮没有说明位置规则 | 两个按钮并列归入“搭建立体”，固定显示“放到空闲格”和“紧贴选中面”；提供常驻说明、悬停及键盘聚焦提示、目标线框、完成后的结果反馈 |
| 展开绘图区域偏小 | 类型缩略图、变换、书签及绘图按钮纵向堆叠；三维预览长期占用接近一半宽度 | 展开编辑器使用接近整窗的空间；画板成为主体；类型、变换和书签移到可收起侧栏；“展开布局”和“折叠预览”分为两个页签 |
| 单面编辑和展开编辑似乎重叠 | 没有区分精细绘制一个面与跨面绘制；当前面不够醒目 | 保留两个入口；工具栏明确显示“只编辑面 B”与“六面联动编辑”；展开内部增加“放大编辑面…”和“返回六面展开”，不再为细画一个面叠加窗口 |
| 按钮杂乱 | 建模、相机、画笔、底色、文件和历史操作同等突出 | 工具按工作任务分组；底色、单体旋转、删除集中到“单体设置”；导出归入独立入口；选区工具收为下拉选择，文字输入仅在文字工具启用时显示 |

这些调整没有删除单面编辑、颜色、旋转、选区、展开候选或折叠功能。低频选项通过明确入口展开，常用操作仍直接可见。

## 2. 新的操作方式

### 搭建立体

- **添加立方体**：在活动组件组的空闲格放置一个新立方体，不以选中面决定位置。
- **贴面堆叠**：沿选中面的外侧新增一个，继承底色；相邻格占用时不会重复添加。
- 工具栏显示当前单体和面；鼠标悬停或键盘聚焦会显示进一步说明及目标位置线框。
- 两个操作都保持直接执行和场景撤销，不增加逐次确认弹窗。

### 绘制图案

**编辑选中面**适合直接细画一个已选中的面。标题写明单体和面名，完成后立体及展开图中的同一面都会更新。

**展开选中**适合同时观察六面、跨面绘制和调整展开布局。画板上方的“当前编辑面”可以用鼠标或键盘选择面，点击“放大编辑面 A”后只显示 A 的原始图案；“返回六面展开”恢复展开视图。

两种展开内视图共用同一个 `EditSession` 和历史栈。切换视图不提交场景、不创建第二个模态窗口，也不自动记录一条笔画历史。最终仍由“应用到立方体”统一提交，取消会丢弃整次草稿。独立单面编辑保留自己的完成／取消边界。

在六面画板中选择一个面，仅表示当前关注的面；画笔仍可跨面绘制。只有进入“放大编辑面…”后，画板范围才限定为单面。状态栏和工具提示分别说明这两种范围。填充遵循当前画板及选区范围。

### 查看画板

- **放大／缩小画板**：改变显示比例，源图案仍保持原来的 256×256 像素，不反复重采样。
- **适应画板**：回到完整可见的取景。
- **拖动画板**：切换为移动视野；点击绘图工具后自动退出拖动模式。
- 放大后可以使用滚动条。整图旋转后的滚动范围包含完整旋转边界，画板边角不会因为容器尺寸仍按旋转前计算而被裁掉。
- **收起侧栏**：将横向空间交还给画板；窄屏默认收起，通过“展开布局 / 预览”打开，通过“返回画板”关闭。

在 1440×1000 的浏览器视窗下，自动化验证绘图区宽度大于 950px、高度大于 580px；当前截图约为 1055×628px。此前画板高度受 `40vh` 限制，在同样视窗下约为 400px。单面细画则将整个绘图区用于一个面。

## 3. 实现边界

- 新增 `src/draw/CanvasViewport.ts`，统一管理单面和展开编辑器的显示缩放、旋转边界、滚动与拖动，复用 Painter 的坐标映射。
- `NetEditor` 的单面细画读写六面草稿中对应的一张画布；六面模式继续使用既有展开映射，具体展开算法没有改动。
- `Toolbar` 只组织任务入口和反馈；新增与堆叠的位置算法、占用规则及撤销规则不变。
- `ViewBar` 将相机、学习和显示相关入口分组；组件组的步进按钮统一样式，并修正旋转中心工具提示中遗留的“不保存”说明。
- 编辑器关闭时释放缩放区域监听；收起折叠页时停止播放，避免隐藏后继续动画。

## 4. 验收

执行 `npm run build`、`npm test`、`npm run test:e2e`。

本轮结果：生产构建通过，11 项几何与数据测试通过，16 项浏览器回归通过。

在原有 12 条浏览器回归基础上新增 4 条：

1. 选中上表面后贴面堆叠得到 `(0,1,0)`，再普通新增得到空闲格 `(1,0,0)`，提示与实际结果一致。
2. 独立单面绘制后进入展开编辑，放大另一个面继续绘制；切换面、撤销重做、切换展开类型与返回后图案保留，其他五面不变；同时只有一个编辑窗口。
3. 整图旋转、缩放和拖动后，按实际屏幕坐标放置文字，只有预期的源面发生变化；纯查看操作不添加笔画。
4. 在 390×844 窄屏上操作侧栏、单面细画并提交，绘图区与完成按钮均可到达。

原有窄屏用例已按新侧栏入口更新。几何、文件读取、自动保存、投影和练习的原有回归继续执行。

截图由浏览器测试写入 `test-results/`：`ui-main-desktop.png`、`ui-main-mobile.png`、`ui-single-face-in-net.png`、`ui-net-mobile.png`，不纳入版本控制。

当前验证使用 Chromium 和窄屏模拟；真实触屏设备的手势手感仍需结合使用反馈继续调整。
